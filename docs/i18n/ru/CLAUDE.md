# RPoem — правила разработки (для ИИ)

- Единственный источник описания административного API — crates/open-runo-proto/proto/.../admin.proto.
- Форматировать только через cargo fmt -p <крейт>, не --all (иначе будут затронуты соседние репозитории).
- Не коммитить неотслеживаемые RPoem/ и target-crossui/. Секреты (ключи, токены) не должны попадать в репозиторий и логи.
- Перед сообщением о завершении проверить отображение и работу в реальном браузере (не пропустить белый экран).
- На VPS выполнять только git pull; перезапуск служб и открытие портов — лишь по прямому указанию пользователя.
