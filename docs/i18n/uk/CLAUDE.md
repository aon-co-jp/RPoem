# RPoem — правила розробки (для ШІ)

- Єдине джерело опису адміністративного API — crates/open-runo-proto/proto/.../admin.proto.
- Форматувати лише через cargo fmt -p <крейт>, не --all (інакше зачепить сусідні репозиторії).
- Не комітити невідстежувані RPoem/ і target-crossui/. Секрети (ключі, токени) не повинні потрапляти до репозиторію чи логів.
- Перед повідомленням про завершення перевірити відображення й роботу в реальному браузері (не пропустити білий екран).
- На VPS виконувати лише git pull; перезапуск служб і відкриття портів — тільки за прямою вказівкою користувача.
